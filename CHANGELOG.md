# Changelog

Все заметные изменения AI-Arbitr фиксируются в этом файле. Проект использует Semantic Versioning до стабильного релиза с суффиксом `-beta`.

## [0.9.4-beta] - 2026-09-20

### Исправлено

- Системный жест открытия переключателя приложений больше не распознается как команда возврата на стартовую страницу.
- Активный договор дополнительно сохраняется при потере видимости страницы и выгрузке вкладки.
- Гостевой маршрут подписания восстанавливается до первого рендера, если мобильный браузер вернул вкладку на корневой URL.

### Изменено

- Жест «назад» работает только от левого края экрана; нижняя системная зона смартфона исключена из жестов сервиса.

## [0.9.3-beta] - 2026-09-19

### Исправлено

- Открытая форма подписи и введенные реквизиты восстанавливаются после переключения приложений, перезагрузки или выгрузки мобильной вкладки из памяти.
- Восстановление работает для гостевой формы второй стороны и формы подписи создателя договора.

### Безопасность

- Незавершенные реквизиты хранятся только в `sessionStorage` текущей вкладки и удаляются после успешной подписи.
- Политика конфиденциальности обновлена до версии 1.4; версия единого согласия повышена до 1.1.

## [0.9.2-beta] - 2026-09-19

### Изменено

- Email пользователя и выход из аккаунта объединены в одну компактную строку бокового меню.
- Текст кнопки выхода заменен знакомой иконкой с доступной подписью и всплывающей подсказкой.

## [0.9.1-beta] - 2026-09-19

### Добавлено

- Очевидно посторонние запросы и попытки сменить системную роль отклоняются локально без обращения к нейросети.
- Длина одного сообщения ограничена 4000 знаками для защиты от лишнего расхода токенов.

### Изменено

- Помощник отвечает только по существу текущего договора, его исполнения и применимого права.

## [0.9.0-beta] - 2026-09-19

### Изменено

- После генерации договор продолжается как обычный диалог без постоянной панели вариантов действий.
- Вопросы, просьбы добавить условие и переход к согласованию распознаются по естественному тексту пользователя.
- Форма роли и email появляется внизу ленты только после перехода к согласованию.
- Первая версия договора сопровождается кратким пояснением результата и доступных следующих шагов.

### Добавлено

- Серверный справочник намерений чата и модульные тесты его основных формулировок.

## [0.8.3-beta] - 2026-09-19

### Добавлено

- Кнопка «Сообщить о проблеме» формирует письмо на `ai-arbitr@ya.ru` с описанием ожидаемого и фактического поведения.
- В письмо автоматически добавляются версия, модель, этап, ID договора, экран, устройство, размер окна и время.

### Безопасность

- Диагностика не содержит текста договора и реквизитов, а токен гостевой ссылки заменяется безопасной меткой.

## [0.8.2-beta] - 2026-09-19

### Изменено

- Дорожная карта разделена на «Реализовано» и «В перспективе».
- Выполненные функции привязаны к версиям продукта, будущие функции — к ориентировочным срокам.
- `docs/roadmap.md` назначен главным источником плана развития; README и лендинг синхронизированы с ним.

## [0.8.1-beta] - 2026-09-19

### Исправлено

- Переключение нейросети в существующем чате больше не запускает циклическое открытие двух сессий и мигание экрана.
- Восстановление договора из URL и локального состояния выполняется только один раз при загрузке.
- Запоздавший ответ предыдущего запроса не может заменить уже открытый пользователем договор.

## [0.8.0-beta] - 2026-09-19

### Добавлено

- Единый frontend-справочник подсказок чата, поиска и полей форм.
- Контекстные подсказки для создания договора, вопросов, новых условий и описания спора.
- Поисковые подсказки по собственной истории договоров пользователя.
- Управление подсказками клавишами, касанием и привычными командами выбора и закрытия.
- Документирован общесистемный каталог UX-паттернов.

### Изменено

- Одинаковые поля регистрации и подписания используют единые примеры форматов.
- Результат поиска можно открыть непосредственно из списка подсказок.

## [0.7.0-beta] - 2026-09-19

### Добавлено

- Единый справочник типов договоров, юридических названий, ролей сторон, шаблонов и полей карточек.
- Действующие типовые формы найма жилья и разработки сайта подключены через каталог.
- Метаданные типа договора возвращаются в списке сессий, детальной сессии и гостевом просмотре.
- Публичный справочник типов доступен через `/api/contracts/catalog`.
- Добавлены тесты распознавания типов и целостности каталога.

### Изменено

- Название договора, роли сторон, версия шаблона и аналитическая категория определяются одним справочником.
- Карточки договоров без типовой формы используют собственный компактный набор полей вместо условий найма жилья.

## [0.6.0-beta] - 2026-09-19

### Добавлено

- Единый backend-справочник этапов договора, пользовательских действий и разрешений для обеих сторон.
- API сессий возвращает текущий `workflow`, доступные действия и их пользовательские названия.
- Публичный справочник процесса доступен через `/api/workflow/catalog`.
- Недопустимые переходы блокируются сервером с указанием текущего этапа и допустимых действий.
- Добавлены модульные тесты жизненного цикла и архитектурная документация.

### Изменено

- Категории истории договоров определяются по серверному этапу процесса вместо набора frontend-эвристик.
- Ошибки API отображаются в едином человекочитаемом формате.

## Политика стабилизации 0.4.x

- В ветку `0.4.x` входят исправления ошибок, безопасности, мобильной совместимости и ключевого клиентского пути.
- Новые крупные функции сначала фиксируются в дорожной карте и получают следующую минорную версию.
- Каждый публичный релиз проходит сборку frontend, компиляцию backend, проверку миграций и smoke-тест основных URL.
- Стабильная контрольная точка отмечается Git-тегом формата `v0.4.0-beta`.
