# Справочник типов и типовых форм

Соответствует приложению: `0.9.2-beta`

Единый каталог расположен в `backend/app/catalogs/contracts.py`. Он используется для распознавания запроса, юридического названия договора, ролей сторон, выбора типовой формы, версии шаблона и состава карточки ключевых условий.

## Типы MVP

| ID | Юридическое название | Роли | Форма |
| --- | --- | --- | --- |
| `housing_rent` | Договор найма жилого помещения | Наймодатель / Наниматель | Типовая |
| `website_development` | Договор на разработку сайта | Заказчик / Исполнитель | Типовая |
| `saas_development` | Договор на разработку программного обеспечения | Заказчик / Исполнитель | Универсальная генерация |
| `construction_work` | Договор подряда | Заказчик / Подрядчик | Универсальная генерация |
| `services` | Договор возмездного оказания услуг | Заказчик / Исполнитель | Универсальная генерация |
| `supply` | Договор поставки | Поставщик / Покупатель | Универсальная генерация |
| `sale` | Договор купли-продажи | Продавец / Покупатель | Универсальная генерация |
| `loan` | Договор займа | Займодавец / Заемщик | Универсальная генерация |
| `nda` | Соглашение о конфиденциальности | Раскрывающая / Получающая сторона | Универсальная генерация |

Неопознанный запрос получает тип `universal` и обрабатывается универсальным промптом.

## Состав записи

- стабильный ID и аналитическая категория;
- юридическое и короткое название;
- маркеры запроса и готового документа;
- две юридические роли;
- ID и версия шаблона;
- поля компактной карточки;
- необязательная функция построения типовой формы.

## Добавление типовой формы

1. Добавить проверенный текст и builder в `services/contract_templates.py`.
2. Добавить или обновить `ContractType` в каталоге.
3. Указать собственные `template_id` и `template_version`.
4. Описать поля карточки и роли сторон.
5. Добавить примеры разных пользовательских формулировок в `test_contract_catalog.py`.
6. Проверить юридическое название, обязательный раздел AI-Arbitr, карточку и PDF.

Frontend получает метаданные типа вместе с сессией. Публичная версия справочника доступна через `/api/contracts/catalog`.
