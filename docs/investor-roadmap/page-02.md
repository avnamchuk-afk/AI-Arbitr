# Свобода выбора нейросети. Единые правила AI-Arbitr

**Срок реализации: январь 2027 года**

## Разные нейросети — единая методология

Нейросети отличаются стилем общения: Яндекс отвечает лаконичнее, Qwen — подробнее. Пользователь сам выбирает модель по своим предпочтениям.

Методология AI-Arbitr, скиллы, сценарии и системные инструкции задают общие требования к подготовке договоров, анализу споров, добросовестности и балансу интересов сторон. Соблюдение этих требований проверяется испытаниями, а не предполагается автоматически.

## Своя нейросеть

Планируется подключение сторонних совместимых моделей по API-ключу пользователя — например, через OpenAI API.

Выбранная модель работает в привычном интерфейсе AI-Arbitr с сохранением истории договоров, документов и контекста обсуждений. API-ключи хранятся защищённо; расходы на обращения к модели определяются условиями её поставщика.

## Ожидаемый результат

Пользователь получает свободу выбора нейросети без отказа от методологии и инструментов AI-Arbitr. Сервис снижает зависимость от отдельного поставщика, сохраняя единые требования к качеству работы.

**Основной принцип: нейросеть выбирает пользователь, правила работы задаёт AI-Arbitr.**
