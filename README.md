# AI-Arbitr 🚀

**AI-Arbitr** — это open-source LegalTech-платформа, которая превращает создание контракта, электронное подписание и разрешение споров в единый бесшовный цикл внутри диалогового чат-интерфейса. 

Платформа создана для защиты интересов физлиц, самозанятых, ИП и представителей МСП, для которых классический судебный процесс по мелким сделкам (до 100 000 рублей) экономически нецелесообразен.

## ⚖️ Философия платформы: Новая культура деловых отношений

В отличие от классических CLM-систем, AI-Arbitr базируется на балансе интересов, равенстве сторон и стимулировании открытого диалога:

1. **Свобода договора и ИИ-баланс:** Стороны вольны фиксировать любые условия. Чтобы исключить скрытые ловушки, которые сильная сторона обычно навязывает слабой, системный промпт AI-Arbitr изначально требует от нейросети генерировать **максимально сбалансированный и справедливый договор**, защищающий интересы обоих участников.
2. **Презумпция добросовестности (ст. 10 ГК РФ):** AI-Arbitr исходит из добросовестности обеих сторон, анализирует договор, представленные факты и историю взаимодействия. Сервис формирует мотивированное рекомендательное заключение, которое не заменяет судебный акт, но может быть добровольно исполнено или использовано вместе с материалами договора при обращении в суд.
3. **Право исправить нарушение:** При просрочке AI-Arbitr сначала направляет уведомление и оставляет три рабочих дня для ответа или добровольного исполнения. Если реакции нет, сервис формирует второе уведомление: цитирует условие договора об ответственности и рассчитывает сумму требования. Изменение сроков стороны при необходимости согласуют самостоятельно вне сервиса.

AI-Arbitr — это «фильтр на добросовестность». Он защищает тех, кто готов вести бизнес прозрачно и договариваться в любой ситуации.

## ✨ Что умеет MVP прямо сейчас

- 🏡 **Флагманский сценарий найма жилья:** Юридически выверенный базовый шаблон. В процессе диалога с ИИ-ботом можно «на лету» уточнять, дописывать и гибко кастомизировать любые условия контракта или дополнительных соглашений без потери баланса сторон.
- 🛠️ **Универсальная генерация ИТ-подряда и услуг:** Создание рабочих черновиков договоров по упрощенному текстовому промпту пользователя через универсальный ИИ-промпт.
- ✉️ **Бесплатная подпись по email (0 руб.):** Никаких платных СМС-пакетов. Отправка ссылки контрагенту на почту. Подписание в один клик через Простую Электронную Подпись (ПЭП) в рамках 63-ФЗ.
- 📂 **Защищенный архив и Паспорт сделки:** Все подписанные контракты и допники защищены от удаления. К каждому файлу генерируется неизменяемый `Audit Log` (таймстампы, IP, User-Agent, почтовые заголовки DKIM/SPF) для защиты легитимности.
- ⚖️ **Кнопка «Открыть спор»:** Запуск онлайн-разбора конфликта с анализом договора и истории взаимодействия. AI формирует предварительное рекомендательное заключение, которое не заменяет решение суда.

## 🛠️ Стек технологий (Tech Stack)

Проект построен на современном асинхронном стеке:
- **Backend:** Python (FastAPI / Uvicorn)
- **Frontend:** HTML5, CSS3, JavaScript (Веб-интерфейс чата)
- **AI Core:** Интеграция с LLM-моделями через API для обработки промптов, обеспечения баланса условий и мгновенного арбитража.
- **Инфраструктура:** Развернуто на выделенной ВМ в Yandex Cloud (Intel Ice Lake, 2 vCPU, 4 GB RAM, 100% гарантированная доля). Перед бэкендом настроен Nginx.
